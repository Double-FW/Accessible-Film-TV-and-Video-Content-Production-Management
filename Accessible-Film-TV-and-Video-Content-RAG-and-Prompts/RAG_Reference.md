# Retrieval reference

This index routes to the maintained documents in this repository. It replaces an embedded six-document snapshot from 8 November 2026, which could diverge from corrected source files. The older text remains in Git history; it is not repeated as current guidance. There is no bundled source-copy directory.

**To use:** attach this index plus the relevant owning documents, or retrieve those files with their actual Git revision. Attaching the index alone does not supply their content. A filename, source ID or link is not evidence that a source was read. Preserve the authority, status, scope, rights and evidence distinctions in each retrieved chunk. Example prompts are task data, not runtime permission.

S001–S006 retain their navigation meanings, with the two crosswalks migrated to Markdown filenames. These IDs identify local documents; they are not test or requirement IDs. Source revisions must come from the actual retrieval and must not be inferred from this index's date.

## Retrieval recipe

1. Read S002 for scope and S008 for terminology. Agents working in this repository also read S003.
2. Retrieve the relevant service section in S001; add S004 or S005 for specialist dependencies and S007 for handoffs.
3. Inspect the relevant public owning guidance through S009. Record the exact revision and heading actually used; do not infer external applicability.
4. Return a concrete draft with source statements, project evidence, assumptions, open decisions and proposed actions separated. Missing material remains unknown or not tested.
5. Check rights through S006/S010. Keep private assets, credentials and participant information out of public source material.
