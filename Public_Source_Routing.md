# Public source routing

All repositories below were confirmed public through the GitHub repository API on 20 November 2026. This records visibility at inspection, not a promise of permanent availability or a complete content, legal or rights audit. The machine-readable [repository register](public-repository-links.json) records the same destinations. ## Retrieval and fallback

1. Start with the production question and the owning specialist source; add another source only where it changes the decision or fills a gap.
2. Preserve source revision, heading, status, requirement namespace and applicability. A crosswalk is navigation, not proof that a requirement was met.
3. Separate law, contract, adopted local control and editorial recommendation. Double-FW secondary guidance does not replace current legislation, regulator codes or commissioner/platform specifications.
4. If a repository or exact file becomes unavailable, record the limitation. Use a relevant public replacement only after inspecting it. Do not publish private content, infer its contents or treat the missing dependency as satisfied.
5. Do not bulk-ingest all linked repositories by default. Check necessity, rights, privacy and provenance for each selected source. The MIT licence here does not relicense another repository or external work.
